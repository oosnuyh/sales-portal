제안서 폰트·컬러 정리 도구

PPTX를 업로드해 내부 XML을 분석하고, 사용된 폰트·색상을 원하는 디자인 시스템 값으로 한번에 치환한 새 PPTX를 만듭니다.

1 PPTX 업로드

제안서 파일(.pptx)을 올려주세요. 브라우저 내에서만 처리되며 외부 서버로 전송되지 않습니다.

📎
클릭하거나 파일을 끌어다 놓으세요
.pptx / .potx 파일 지원

2 PPTX → XML 변환

업로드한 PPTX 내부 압축을 풀어 모든 XML 파트로 변환했습니다. 이 XML을 기준으로 폰트·색상이 분석·치환됩니다. 항목을 클릭하면 실제 변환된 XML을 확인하거나 직접 편집할 수 있습니다.

변환 대기 중

3 디자인 시스템 적용 & 치환 값 입력

위에서 변환된 XML을 분석해, 테마(전체 디자인)에 지정된 값과 슬라이드에 개별적으로 지정된(하드코딩된) 값을 구분해서 보여드립니다. 필요하면 아래에서 색상표 이미지를 올려 색상 코드를 확인한 뒤, 표에서 각 항목의 변경할 값을 직접 입력하세요.

이미지를 올리면 자동으로 주요 색상을 추출해 사용 비율 순으로 보여드립니다. 색상 코드 옆 복사 버튼으로 복사할 수 있고, PPT가 이미 분석되어 있다면 아래에 "변경하면 좋을 색상" 추천도 함께 표시됩니다.
🎯 PPT 색상 변경 추천
✒️ 폰트 일괄 통일
🎨 테마 색상 (전체 디자인에 영향)
현재 색상변경할 색상
✒️ 테마 폰트
현재 폰트변경할 폰트
🎨 슬라이드에 직접 지정된 색상 (PPT에서 실제 사용된 색상만 표시)
현재 색상사용 비율변경할 색상
✒️ 슬라이드에 직접 지정된 폰트
현재 폰트변경할 폰트

4 변경사항 확인 후 적용

먼저 미리보기로 XML에서 실제로 몇 건이 바뀔지 확인하세요. 0건으로 표시되는 항목은 해당 값이 XML에 없다는 뜻이니, 위 표의 입력값이나 2단계의 XML 원문을 다시 확인해보세요. 확인 후에만 적용·다운로드할 수 있습니다.
